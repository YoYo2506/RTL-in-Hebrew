# תשובות בעברית מימין לשמאל

הריפו מכיל שני רכיבים עיקריים שעובדים יחד:

1. **הסקריפט `browser/claude-hebrew-rtl.user.js`:** מיישר לימין בדפדפן כל פסקה, רשימה, כותרת וטבלה שנפתחת בעברית, ב-claude.ai וב-Claude Code בדפדפן (claude.ai/code). אנגלית וקוד נשארים משמאל לימין.
2. **התוסף `hebrew-rtl` (סקיל והוק):** גורם ל-Claude לפתוח כל בלוק בתשובה עברית במילה בעברית, כדי שהסקריפט (וכל אפליקציה שמזהה כיוון) יזהה אותו כעברית.

## למה צריך את שניהם

הכיוון והיישור נקבעים על ידי האפליקציה שמציגה את התשובה, ולא על ידי Claude. ב-claude.ai, ב-Claude Code בדפדפן וב-Claude Desktop התצוגה קבועה כרגע לשמאל-לימין, ולכן סקיל לבדו לא יכול ליישר לימין.

הסקריפט קובע את הכיוון של כל בלוק לפי האות הראשונה בו, כמו אלגוריתם ה-BiDi של Unicode. פסקה בעברית שנפתחת ב-`GDPR` תזוהה כאנגלית ותישאר משמאל. כאן נכנס הסקיל: הוא מוודא שהפסקה תיפתח ב"ה-GDPR".

## התקנה בדפדפן (Chrome, Edge, Firefox)

1. להתקין את התוסף Violentmonkey (קוד פתוח) מחנות התוספים של הדפדפן.
2. לפתוח את לוח הבקרה של Violentmonkey, ללחוץ על `+` וליצור סקריפט חדש.
3. למחוק את התוכן שמופיע, להדביק את כל התוכן של `browser/claude-hebrew-rtl.user.js` ולשמור.
4. לרענן את הלשונית של claude.ai.

אם Chrome מבקש, יש להפעיל בדף הפרטים של התוסף את האפשרות Allow User Scripts.

## Claude Desktop

אין דרך נתמכת להוסיף סקריפט או עיצוב לאפליקציית הדסקטופ. הפאצ'ים שקיימים ברשת משנים את קבצי האפליקציה, נשברים בכל עדכון, ולפי דיווחים חלקם שוברים את Cowork. ההמלצה: לעבודה בעברית להשתמש בדפדפן עם הסקריפט, ולהצביע בעד הבקשה הרשמית לתמיכה ב-RTL (anthropics/claude-code#16814).

## פרטיות

תוסף שמריץ סקריפטים יכול לקרוא את התוכן של הדפים שבהם הוא פועל, כולל שיחות עם מידע חסוי. לכן:

- הסקריפט מוגבל ל-`https://claude.ai/*` בלבד.
- הסקריפט קורא רק את הטקסט שעל המסך, לא שולח שום דבר לרשת ולא שומר מידע. אפשר לוודא זאת בקריאה, הוא קצר.
- אין בו כתובת לעדכון אוטומטי, כך שאיש לא יכול להחליף אותו מרחוק.
- התוסף עצמו (Violentmonkey) הוא קוד פתוח. ההחלטה אם להתקין תוסף על דפדפן שבו מטופל מידע של לקוחות היא שלך.

## הוראה קבועה במקום סקיל, או בנוסף לו

סקיל נטען רק כש-Claude מחליט שהוא רלוונטי, ובשאלה פשוטה בעברית הוא עלול לא להיטען. לכלל שצריך לחול על כל הודעה, הוראה קבועה אמינה יותר. מומלץ להוסיף את השורות הבאות גם להעדפות האישיות ב-claude.ai וגם לקובץ `~/.claude/CLAUDE.md` של Claude Code:

```text
כשאתה עונה בעברית: פתח כל פסקה, כל פריט ברשימה, כל כותרת וכל תא בטבלה במילה בעברית.
אל תפתח שורה במונח באנגלית, בשם חוק, בפקודה או בנתיב; הוסף לפניו מילה בעברית
(למשל "ה-GDPR", "חוק ה-CCPA", "הפקודה `npm install`"). השאר מונחים באנגלית כפי שהם,
בלי תעתיק. אל תוסיף הערות על כיווניות.
```

## התקנת הסקיל וההוק (תוסף `hebrew-rtl`)

הסקיל וההוק ארוזים יחד בתוסף אחד, `hebrew-rtl`, בתיקייה `plugin/hebrew-rtl`:

- **הסקיל:** כללי הכיווניות המלאים. עובד בצ'אט וב-Claude Code, כשClaude מחליט לטעון אותו.
- **ההוק:** רץ על כל הודעה ב-Claude Code. אם יש בה עברית, הוא מצרף לה את הכלל המרכזי. בצ'אט הוקים לא רצים, ושם ההוראות הקבועות עושות את העבודה.

תוסף שנשמר בחשבון מסתנכרן לצ'אט בדפדפן ובדסקטופ ול-Claude Code שמחובר לאותו חשבון.

**התקנה דרך ה-marketplace של הריפו (מומלץ):**

1. לפתוח את Plugins, ללחוץ על Add ולבחור Add marketplace.
2. לבחור Add from a repository ולהזין `YoYo2506/RTL-in-Hebrew`.
3. להתקין מתוכו את התוסף `hebrew-rtl` ולוודא שהוא מופעל. הוספת marketplace לבדה לא מתקינה את התוספים שבו.
4. לפתוח סשן חדש של Claude Code. תוספים מסתנכרנים בתחילת סשן.

אפשר גם להתקין ישירות מתוך Claude Code, אבל אז התוסף נשמר רק במחשב הזה ולא בחשבון:

```text
/plugin install hebrew-rtl --marketplace YoYo2506/RTL-in-Hebrew
```

**התקנה מקובץ:** במסך Plugins לבחור בהעלאת תוסף מותאם אישית ולהעלות את `hebrew-rtl-plugin.zip`.

**לא להתקין גם את הסקיל לבד:** הקובץ `hebrew-rtl.zip` מכיל רק את הסקיל, לשימוש בלי התוסף. התקנה של שניהם תיצור שני עותקים של אותו סקיל.

**דרישה:** ההוק הוא סקריפט bash. ב-Mac וב-Linux הוא קיים מראש, וב-Windows צריך Git for Windows (Git Bash).

## בדיקות

- **הסקריפט:** `node browser/test/run.js` (דורש Playwright) מריץ את הסקריפט על דף שמדמה שיחה ובודק את הכיוון של כל בלוק. הדף מדמה את המבנה של תשובה, אבל הסקריפט לא נבדק מול claude.ai עצמו.
- **הסקיל:** `hebrew-rtl/scripts/check_rtl_openers.py` בודק תשובה בפורמט Markdown ומדווח על כל בלוק בעברית שנפתח באות לטינית. תרחישי הבדיקה נמצאים ב-`hebrew-rtl/evals/`.
